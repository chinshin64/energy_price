# 风控蓝军测试系统

## 产品功能

### 测试总览

- 目标平台统计
- 去重场站统计
- 总记录数统计
- 链路状态展示

### 页面模拟验证

- 页面访问
- 搜索浏览
- 下滑采集
- OCR 识别
- 页面证据生成

### 业务请求验证

- 请求录制
- HAR 导入
- 模板学习
- 字段识别
- 请求证据归档

### 自动化采集验证

- 目标位置解析
- 坐标网格生成
- 列表模板执行
- 详情模板执行
- 请求预算控制

### 证据中心

- 报告列表
- 报告详情
- 风险发现
- 证据矩阵
- 复测标准
- 原始请求证据

### AI 中心

- 异常场景选择
- 链路诊断
- 修复建议
- 规则兜底

### 手机交互控制

- 设备状态
- 指令解析
- 任务下发
- 执行进度
- 结果回传

### 系统配置

- 平台配置
- 网络代理
- 城市代理池
- 定时任务
- 运行参数

./start-local-preview.sh
