## 本地启动

面向普通使用者优先打开主工作台；下面命令仅用于本机开发和联调。

```bash
./start-local-preview.sh
```

```bash
cd backend
npm install
cd ..
./start-backend.sh
```
# 分布式 Edge Agent

主服务现已支持 Android、macOS 和 Windows 节点统一登记、心跳、任务租约、子 Agent
委派和按出口 IP 属地调度。管理入口位于产品的“手机辅助通道 / 跨端协同”。

桌面 Agent 源码和配置位于 `edge-agent/desktop`，Android 客户端位于 `mobile/android`。
执行 `scripts/package-edge-agents.sh` 会在 `dist/edge-agents` 生成各平台压缩包和 SHA-256
校验清单。设备档案仅包含操作系统公开信息和本地加盐哈希，不读取或修改微信内部设备
指纹、硬件序列号、MAC 地址或 Android ID。
