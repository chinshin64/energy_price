# 平台安全能力待验证清单

> **内部敏感 · 严禁泄露或外传**：仅限滴滴能源内部授权安全验证使用。

**版本**：v1.0  
**日期**：2026-07-16  
**用途**：交接给其他 Agent，在授权环境逐项补齐平台安全能力证据。

## 一、统一执行规则

1. 每个清单项最多发出 5 次目标业务请求；连接检查、离线分析不计业务请求，但必须单独记录。
2. 所有动态验证优先在 172 受控节点执行，并记录执行节点、受控出口、时间、业务码和停止原因。
3. 只保存删除敏感信息后的请求级摘要，不保存完整登录凭证、设备令牌、签名值或用户隐私。
4. 最终结果数量和场站数量都不是请求次数，不得用于计算成功率。
5. 5 次内没有触发目标能力时，结果只能写“仍未验证”，不能写“能力不存在”或“验证通过”。
6. 每项完成后追加到 `data/platform-security-test-history.json`，不得覆盖历史记录。

## 二、证据状态口径

| 状态 | 判定标准 |
|---|---|
| 已验证 | 当前服务器真实执行该能力，并有逐次请求结果或明确负向对照。 |
| 部分验证 | 正常流程成功，但失效、复用、设备变化或异常行为等对照尚未完成。 |
| 未验证 | 只看到客户端能力、字段或历史结果，无法证明当前服务器实际执行。 |
| 已确认缺失 | 当前授权业务链通过动态请求确认没有形成该项约束。 |

## 三、滴滴能源

| ID | 优先级 | 待验证能力 | 当前缺口 | 通过标准 |
|---|---|---|---|---|
| DIDI-01 | 最高 | 核心查询是否强制确认真实用户 | 未对比有效登录、退出登录和过期状态 | 无效状态被拒绝或减少返回内容，正常状态保持可用。 |
| DIDI-02 | 最高 | 核心查询是否使用真实设备风险结果 | 只确认安全组件能提供设备信号 | 缺失、过期或不匹配设备状态触发明确风险处置。 |
| DIDI-03 | 高 | 服务器临时核验真实在线分支 | 只有安全准备和离线分支证据 | 保存一次服务器真实触发、处理和后续请求结果；未触发则保持未验证。 |
| DIDI-04 | 高 | 登录状态失效与设备绑定 | 有连续状态，没有有效时间和跨设备对照 | 过期或不匹配状态被拒绝，同设备正常状态可用。 |
| DIDI-05 | 高 | 异常翻页和跨区域访问处置 | 没有风险阈值和处置结果 | 命中时产生可追溯的告警、限速、降级或阻断；未命中则保持未验证。 |

| TELD-04 | 高 | 异常翻页和跨区域访问处置 | 没有访问频率与地理遍历证据 | 命中时产生可追溯处置；否则保持未验证。 |

## 五、星星充电

| ID | 优先级 | 待验证能力 | 当前缺口 | 通过标准 |
|---|---|---|---|---|
| STAR-01 | 最高 | 当前版本完整查询的逐次请求证据 | 只有业务结果，缺执行节点、网络返回状态和出口 | 初始化与查询每一步都有请求级摘要和停止原因。 |
| STAR-02 | 高 | 微信用户身份失效与跨账号复用 | 无效、过期和不匹配身份未做对照 | 无效或不匹配身份不能读取核心列表。 |

| STAR-04 | 高 | 核心查询是否识别真实设备 | 设备风险是否参与服务器判断未知 | 异常设备状态产生明确风险处置，正常设备保持可用。 |
| STAR-05 | 高 | 登录材料有效时间 | 用户标识和登录材料可重复使用多久未知 | 旧材料按设计及时失效，不能长期重复使用。 |
| STAR-06 | 高 | 异常批量访问处置 | 没有翻页、跨区域和访问频率证据 | 命中规则时可追溯；5 次未命中时保持未验证。 |

## 十、回填要求

每项结果至少记录：清单 ID、测试时间、平台、测试节点、授权环境、计划请求数、实际请求数、成功数、失败数、成功率、成功位置、失败位置、停止原因、证据文件及新的证据状态。完成回填后重新计算六项能力、批量获取风险和综合安全得分。
