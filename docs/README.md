## 文档规则

- 普通用户入口优先使用产品语言，避免直接暴露请求记录组件、模型配置、凭证材料等内部实现词。
- 开发服务路径和排障命令只能出现在服务能力、部署、测试或技术附录语境中。
- 不写入内部节点、远端地址、真实凭证和临时验证过程。
