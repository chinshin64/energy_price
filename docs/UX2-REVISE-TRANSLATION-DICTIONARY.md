# 风控风险表达规范

> 版本：revise-1.0
> 日期：2026-06-17
> 目标：让运营、管理层和安全团队都能看懂风险，同时避免弱化安全语义。

## 1. 表达原则

- 用业务语言解释风险，不把内部检测标记直接展示给普通用户。
- 严重风险不能弱化，例如越权、批量遍历、持续爬取、凭证异常必须明确标注风险。
- 所有百分比必须同时展示绝对数字。
- 处置动作必须可审计，不能因为“误报”就全量豁免。
- 管理层页面只展示摘要、影响面、置信度和当前状态，不展示原始明细。

## 2. 风险名称规范

| 风险类型 | 运营展示 | 管理层展示 | 说明 |
| --- | --- | --- | --- |
| 未经身份验证访问 | 无身份直达风险 | 未授权访问风险 | 必须强调越权风险，不能写成“缺少字段” |
| 合法匿名访问 | 合法匿名访问 | 正常匿名流量 | 必须和无身份直达严格区分 |
| 身份异常切换 | 同一设备多身份标识 | 身份频繁切换风险 | 表示疑似身份伪造，不只写“多标识” |
| 凭证跨场景使用 | 凭证跨应用使用 | 凭证复用风险 | 强调异常复用和泄露可能 |
| 批量资源遍历 | 批量资源遍历 | 大规模资源遍历风险 | 不能弱化成普通探测 |
| 扫描行为 | 访问扫描 | 侦察行为 | 需要标注风险意图 |
| 凭证试探 | 安全凭证试探 | 凭证窃取尝试 | 必须标红或高亮 |
| 持续数据爬取 | 持续数据爬取 | 持续性数据抓取 | 不能弱化为普通采集 |
| 高频访问 | 请求频率异常 | 访问频率超限 | 必须展示具体数量 |
| 长期持续风险 | 跨天持续攻击 | 长期持续威胁 | 管理层强调持续性 |
| 综合评分异常 | 综合风险评分异常 | 多维风险异常 | 不能单独使用，必须附维度说明 |

## 3. 指标展示规范

| 指标 | 运营展示 | 管理层展示 | 展示规则 |
| --- | --- | --- | --- |
| 请求总量 | 请求总量 | 访问总量 | 必须附时间范围 |
| 拦截比例 | 威胁拦截率 | 安全防护率 | 百分比加分子分母 |
| 未授权访问比例 | 无身份直达率 | 未授权访问率 | 百分比加绝对数字 |
| 误报比例 | 误报率 | 误判率 | 百分比加绝对数字 |
| 批量遍历事件 | 批量遍历事件数 | 资源遍历事件数 | 附时间范围 |
| 数据爬取来源 | 数据爬取源数 | 数据爬取来源数 | 区分活跃和总计 |
| 凭证覆盖 | 凭证覆盖度 | 凭证覆盖率 | 百分比加绝对数字 |
| 凭证可用 | 凭证可用率 | 凭证健康率 | 百分比加绝对数字 |

示例：

| 场景 | 错误写法 | 正确写法 |
| --- | --- | --- |
| 拦截比例 | 拦截率 96.3% | 拦截率 96.3%（1.62 亿 / 1.68 亿） |
| 误报比例 | 误报率仅 2% | 误报率 2%（387 条 / 19350 条） |
| 爬取占比 | 爬取占比 0.5% | 爬取占比 0.5%（84 万 / 1.68 亿） |

## 4. 管理层风险清单

管理层页面必须展示“未处理风险清单”：

| 字段 | 说明 |
| --- | --- |
| 风险等级 | 紧急、关注、观察 |
| 风险描述 | 使用业务语言说明问题 |
| 影响面 | 请求次数、账号数、持续天数等绝对数字 |
| 置信度 | 高、中、低 |
| 当前状态 | 待处理、处置中、观察中 |
| 责任人 | 当前负责团队或人员 |
| 持续时间 | 首次发现至今 |

展示规则：

- 默认最多展示 5 条。
- 按风险等级和置信度排序。
- 高风险且高置信度排最前。
- 点击风险条目进入详情页。
- 管理层页面不展示原始数据。

## 5. 置信度规范

| 置信度 | 含义 | 展示示例 |
| --- | --- | --- |
| 高 | 有明确证据或已人工确认 | 高置信度，已验证影响面 |
| 中 | 检测命中但需人工确认 | 中置信度，待复核 |
| 低 | 新出现模式，证据不足 | 低置信度，需排查 |

每条风险必须附带判定依据，例如命中规则、影响面、持续时间或人工确认记录。

## 6. 处置动作规范

处置动作可以组合，不应设计成互斥：

| 操作 | 含义 | 组合规则 |
| --- | --- | --- |
| 标记误报 | 当前告警不成立 | 可同时创建工单或加入观察 |
| 加入阻断 | 对风险来源执行访问限制 | 可同时创建工单 |
| 创建工单 | 进入追踪流程 | 可与其他动作组合 |
| 加入观察 | 暂不阻断，持续观察 | 适合中低置信度 |

## 7. 误报豁免规则

误报只豁免特定条件组合，不能豁免全部行为。

| 豁免维度 | 说明 |
| --- | --- |
| 来源 + 凭证材料 | 只豁免该来源使用该材料触发的告警 |
| 来源 + 业务路径 | 只豁免该来源访问该业务路径的告警 |
| 来源 + 规则类型 | 只豁免该来源在该规则类型下的告警 |

禁止：

- 按来源全量豁免。
- 批量豁免高风险告警。
- 没有审批记录的长期豁免。

## 8. 审批规则

| 场景 | 审批要求 |
| --- | --- |
| 单条误报 | 运营可直接操作 |
| 2 到 10 条批量误报 | 需要另一名运营确认 |
| 超过 10 条批量误报 | 需要运营负责人和产品经理审批 |
| 涉及紧急风险 | 必须产品经理审批 |

## 9. 巡检规则

| 阶段 | 目标 | 内容 |
| --- | --- | --- |
| 3 分钟查看 | 快速掌握态势 | 看摘要、告警卡片和未处理风险清单 |
| 处置阶段 | 按需处理 | 误报、阻断、工单和复核 |

页面顶部展示巡检状态：

- 已查看。
- 有待处置项。
- 有紧急待处置。

处置时间不计入 3 分钟查看考核。
